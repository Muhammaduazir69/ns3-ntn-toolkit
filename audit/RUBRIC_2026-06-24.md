### A.3 RRC/SIB19 (TS 38.331)

### A.4 Mobility/HO (TS 38.331 §5.5.4)
- CondEvent D1 (Rel-17 fixed ref): enter Ml1−Hys>Thresh1 AND Ml2+Hys<Thresh2; distanceThreshFromReference1/2 (50 m).

### A.5 HARQ/MAC/PHY (TS 38.321/213)
- ≤16 DL HARQ processes (no gain beyond 16 per 38.821 — reject "32/64" claims). Per-process feedback disable via UE-specific RRC bitmap → disabled rely on RLC ARQ. DRX HARQ-RTT/retx timers extended by satellite RTT.
- SCS: 15/30 kHz FR1-NTN; 60/120 kHz FR2-NTN. Bands n255(L)/n256(S) Rel-17; n254, n510/511/512(Ka) Rel-18.
- CSI/CQI aging ~10-12% loss at 40-46 ms feedback delay.

### A.6 Release frontier
Rel-17 frozen 2022 (transparent only, IoT-NTN, SIB19, D1/T1). Rel-18 frozen 2024 (FR2/Ka n510-512, D2, NTN enhancements). **Rel-19 frozen Dec 2025**: regenerative payload = full gNB onboard + Xn/ISL + inter-sat mobility; store-and-forward (IoT); RedCap/eRedCap-NTN; MBS-over-NTN.

## B. O-RAN / Space-O-RAN (current spec versions, April 2025 O-RAN release)
Versions: E2AP v7.00, E2SM-KPM v6.00 (≥R003 v3.00), E2SM-RC v7.00, A1 v5.00, O1 v15.00, O2 v8.01, OFH CUS-Plane v17.01.

### B.1 E2/E2AP
ASN.1-APER PDUs over SCTP (one association per E2 node↔RIC). Procedures: E2 Setup (RAN Function list w/ ID+OID+description, explicit accept/reject), RIC Subscription/Delete/Modification (+…Required), RIC Indication (distinct Header/Message/Call-Process-ID; REPORT vs INSERT), RIC Control (Request→Ack/Failure), Service Update, E2 Node Config Update, Reset, Error Indication.

### B.2 E2SM-KPM
Measurement names from 3GPP TS 28.552 (DRB.UEThpDl/Ul, DRB.RlcSduTransmittedVolumeDL, DRB.AirIfDelayDl, RRU.PrbTotDl, RRU.PrbUsedDl, RRC.ConnMean/Max, TB.TotNbrDl, QF.EstabAttNbr, MM.HoPrepInterReq, CARR.WBCQIDist). Granularity Period (collectStartTime + ms). Event Trigger Format 1 (period ms). Indication Formats: 1 (single UE), 2 (label/condition-matched), 3 (list of UE-IDs). Cell-level AND UE-level. NTN Doppler/sync names are NON-standard extensions (flag).

### B.3 E2SM-RC
Numbered Control Styles + Action IDs. Style 1 Radio Bearer/QoS (RBC); Style 2 Radio Resource Allocation (slice PRB quota, DRX, SPS); Style 3 Mobility — Action 1 Handover, Action 2 Conditional HO, Action 3 DAPS. INSERT→CONTROL pattern (stall call process, await RIC).

### B.4 Split / RIC placement / NTN
- 7.2x OFH one-way ≤~500 µs ⇒ **cannot cross a feeder/ISL**; RU+DU must be co-located/onboard.
- F1 (DU↔CU) ~1.5-10 ms — tolerable over feeder/single ISL hop.
- LEO RTT ~5-20 ms (ground Near-RT RIC OK); GEO >250 ms (ground Near-RT RIC infeasible → onboard/edge RIC). ISL ~1.8-3.6 ms/hop. Near-RT loop must be >10 ms & <1 s.
- Explicit payload mode: transparent (bent-pipe) vs regenerative (onboard s-CU/s-DU or full gNB). Multi-tier RIC (ground Near-RT + onboard Space-RIC + dApps for sub-loop). SMO re-homes E2 nodes from orbital prediction.
Sources: O-RAN NTN WP v08.4 (2025); arXiv:2502.15936 (Space-O-RAN); arXiv:2507.02680 (split/RIC-placement taxonomy).

## C. THz (IEEE 802.15.3d-2017 firm; ITU-R P.676-13 equations verified; rest research-grade)
THz above 100 GHz is largely PRE-STANDARD — reward physics fidelity, do NOT claim 6G/NTN-THz standard conformance.

### C.1 Spectrum
802.15.3d: 252.72-321.84 GHz, BW = integer × 2.16 GHz (≤69.12 GHz), 69 channels, THz-SC-PHY/OOK-PHY, RS(240,224)/LDPC 14/15, ≥100 Gb/s, point-to-point. WRC-19 windows: 275-296, 306-313, 318-333, 356-450 GHz; exclude RR 5.340 passive bands.

### C.2 Propagation (must compute, not assert)
PL_total = FSPL + A_gas + A_rain/cloud + A_scint + misalignment. FSPL = 20log10(4πfd/c) (f² aperture scaling).
Gaseous = **ITU-R P.676-13 line-by-line**, frequency-resolved (NOT constant dB/km):
- Eq1: γ = 0.1820·f·(N″_O2(f)+N″_H2O(f)) dB/km.
- Eq3 line strength: O2 S=a1·1e-7·p·θ³·exp[a2(1−θ)]; H2O S=b1·0.1·e·θ^3.5·exp[b2(1−θ)]; θ=300/T; e=ρT/216.7.
- Eq5 Van Vleck-Weisskopf line shape F_i. Eq6 line widths. Eq7 overlap δ. **Eq8 dry/N₂ continuum (dominant >100 GHz)** + H2O wet continuum (1780 GHz pseudo-line). Line-by-line valid 1-1000 GHz.
- Slant (Eq11-14): altitude-layered integration (δ_i=0.0001·e^((i−1)/100) km) + refraction (Snell spherical, R_E=6371) + P.835 atmospheres. **Scale with elevation θ**; molecular ≈0 for ISL (no water vapour >12 km).
- Rain P.838 γ=k·R^α + P.618 slant; cloud/fog P.840; tropo scintillation P.618. Disable all for ISL.

### C.3 Beam / RIS / ISAC
UM-MIMO array gain ≈10log10(N) (not isotropic); array-of-subarrays hybrid BF; beam squint on multi-GHz BW; LEO Doppler ≈(v/c)·f time-varying from SGP4; pointing error→misalignment loss.
RIS: product-distance PL ∝ (d1·d2)² (NOT specular (d1+d2)²); N² coherent gain; per-cell pattern, |Γ|≤1, phase quantization; near-field model for large THz arrays.
ISAC: derive accuracy from CRB/Fisher info for range/Doppler/angle; ΔR=c/(2B), Δv=λ/(2T); CRB-rate tradeoff; support bistatic NTN geometry.

## Global fidelity invariants (all modules)
1. Real mobility (SGP4 sats + TR 38.811 UE geometry) so elevation/Doppler/path-length are time-varying — no ConstantPosition/Velocity placeholders for active nodes.
2. Headline KPIs (SINR/throughput/BLER/latency/HO-success) measured from the real plane (RxPacketTraceUe, FlowMonitor, real decode), never closed-form-to-CSV or np.random.
3. Energy/dB bookkeeping conserved end-to-end.
4. Each module's own integrated classes exercised by ≥1 example running a real packet/control plane — not bypassed by a scalar adapter.
5. Document provenance; tag standard vs research model.
