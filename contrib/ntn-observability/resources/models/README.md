# ns3-ntn-toolkit — NetSimulyzer 3D model set

Low-poly Wavefront OBJ models for the toolkit's node kinds, so a NetSimulyzer
desktop replay of a toolkit scene shows recognizable shapes instead of default
spheres. Generated by `generate_models.py` (pure Python, no dependency).

## Model ↔ node-kind mapping

The `NtnSceneRecorder` / `NtnNetSimulyzerExporter` write one of these `model`
names per tracked node (see `NtnSceneRecorder::NodeKind`):

| `model` name | file | node kind |
|--------------|------|-----------|
| `sat`      | `sat.obj`      | LEO/MEO/GEO satellite (bus + solar panels + antenna) |
| `ue`       | `ue.obj`       | user terminal / handset |
| `gateway`  | `gateway.obj`  | ground gateway (pedestal + dish) |
| `uav`      | `uav.obj`      | UAV / drone (quad body + rotors) |
| `haps`     | `haps.obj`     | HAPS (lenticular hull) |
| `ship`     | `ship.obj`     | maritime vessel (hull + superstructure + funnel) |
| `aircraft` | `aircraft.obj` | commercial aircraft (fuselage + wings + tail) |
| `ris`      | `ris.obj`      | reconfigurable intelligent surface (panel + post) |
| `earth`    | `earth.obj`    | reference Earth sphere (UV sphere, radius 1) |

`earth` is emitted by the recorder at the origin scaled to the real Earth radius
(NetSimulyzer is local-Cartesian and has no globe of its own); the Cesium path
renders a true geographic globe instead.

## Coordinate convention

`+Z` up, `+X` east, units = metres at model scale 1. The exporter sets a
per-node display `scale`, so absolute sizes here are nominal — satellites are
enlarged at render time so they read at planetary scale.

## Installing into the NetSimulyzer desktop app

The official NetSimulyzer viewer loads models from its configured *resources*
directory (Settings → Resource Path). Copy these `.obj` files there, or point the
viewer's model path at this directory. For the official ns-3 module
(`contrib/netsimulyzer`, Path B) pass the `.obj` path to
`NodeConfiguration`'s `Model` attribute instead of a built-in enum:

```cpp
nc.Set("Model", StringValue("sat.obj"));   // resolves from the viewer model path
```

## Regenerating

```bash
python3 generate_models.py
```

Edit the `make_*()` builders to change geometry; every model is composed from
`box()`, `quad()`, `tri()`, and (for Earth) a UV-sphere helper.
